# Image Processing with OpenCV (Python)

A hands-on lab for learning image processing with OpenCV and Python. It walks through core concepts with explanations and then 12 practical tasks, with a separate notebook of worked solutions.

## Contents

| File | Description |
|------|-------------|
| `Lab_tasks_image_processing.ipynb` | Concepts and 12 lab tasks to complete |
| `Solution_Lab_tasks_image_processing.ipynb` | Worked solutions for every task |
| `Image Processing in Python.pdf` / `.docx` | Printable handout of the lab |
| `house.tiff` | Sample image used in the tasks |

## Topics covered

1. Gray-scaling and color channel separation
2. Image translation
3. Image rotation
4. Scaling and resizing
5. Gaussian blur
6. Brightness and contrast adjustment
7. Cropping a region
8. Drawing shapes on images
9. Canny edge detection
10. A smart-surveillance processing pipeline
11. Histogram analysis and visualization
12. Linear spatial filtering

Also included: an overview of key `cv2` functions and an introduction to convolution.

## Getting started

```bash
git clone https://github.com/Mian-Basam/Open-CV-.git
cd Open-CV-
pip install opencv-python matplotlib numpy jupyter
jupyter notebook Lab_tasks_image_processing.ipynb
```
